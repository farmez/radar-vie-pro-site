# radar-vie-pro-site

Page publique de **RADAR VIE PRO** : la politique de confidentialité exigée par
le Chrome Web Store.

Ce dépôt est public **uniquement** parce que GitHub Pages ne publie pas depuis un
dépôt privé sans abonnement. Il ne contient qu'une page statique — aucun code de
l'application, aucune donnée.

## Publier

Réglages du dépôt → **Pages** → *Deploy from a branch* → branche `main`, dossier
`/ (root)`. L'adresse devient :

```
https://farmez.github.io/radar-vie-pro-site/
```

C'est cette adresse qui va dans le champ « URL des règles de confidentialité » du
Chrome Web Store. Elle doit rester joignable aussi longtemps que l'extension est
publiée.

## Mettre à jour

La page décrit l'état du produit **au 13 août 2026** : l'éditeur n'héberge aucun
service, et ne reçoit donc aucune donnée. Le jour où un service hébergé ouvre,
cette page doit être mise à jour **avant** — pour nommer l'hébergeur, le
fournisseur du modèle de rédaction et les durées de conservation — et la date de
version changée.

Le brouillon de la version hébergée est gardé dans le dépôt privé de
l'application, sous `magasin/politique-confidentialite.md`.
